# 会员优惠与限价发布台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、原生 CSS
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原「油品价格维护」最小闭环上扩展为会员优惠编排与限价发布控制台，数据保存在浏览器
localStorage（键 `dfwlfront-9-price-console-v1`），页面重载后调价单、复核、价签核验、版本链仍一一对应。

## 功能与业务规则

1. **调价单**：选择站点、油品、时段（半开区间，最短 1 小时）与优惠方式（无优惠 / 每升直降 /
   折扣率 / 指定到手价），系统实时计算会员到手价。
2. **时段互斥（R1）**：同站同油品、跨版本链的草稿或已发布单时段不得重叠；同链前后版本不互斥。
3. **价格走廊（R2/R3）**：到手价必须落在「成本保护线 ~ 最高零售价」之间，越界为阻断冲突，不得发布。
4. **触线复核（R4/R5）**：到手价恰好命中上界或下界时须站长复核，填写复核人与依据；未复核 /
   依据缺失不得发布。
5. **发布冻结**：发布后价格与单据冻结不可编辑；调整必须「另立带原因的新版本」，发布时同链旧版本
   自动置为「已被取代」。
6. **撤销恢复**：撤销已发布版本后，自动恢复同版本链上最近一个有效版本；无更早版本则该链暂无
   生效价。
7. **价签核验（R6/R8）**：发布后须登记现场核验，未核验不对会员生效；价签价与到手价不一致同样
   阻断会员侧生效。
8. **限价发布台**：维护站点 × 油品的最高零售价与成本保护线；走廊调整后冻结中的发布价自动按
   R7 重新校验并在冲突台报警。
9. **冲突与规则台**：逐条列出级别（阻断 / 警告）、站点、油品、时段、命中规则（R1~R8）、涉及单据
   与说明。
10. **会员生效看板**：按站点 × 油品展示当前时段实际会员价及未生效原因。

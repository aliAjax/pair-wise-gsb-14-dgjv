# 会员优惠与限价发布台（油品价格维护扩展）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage，刷新/重载后记录、价签核验与版本链会重新对应校验。

## 业务规则闭环

1. **调价单**：选择站点、油品、时段（datetime-local，半开区间）与优惠方式
   （无优惠 / 每升立减 / 会员折扣 / 固定会员价），实时预览优惠后到手价。
2. **限价区间**：到手价必须落在 `[成本保护线, 最高零售价]` 内，越界禁止保存；
   到手价等于上/下限即视为**触线**。
3. **触线复核**：触线单据必须由站长复核并写明依据（文件/核算单/审批单号），
   未复核的单据命中 `TOUCH_UNREVIEWED`，发布按钮禁用。
4. **时段不重叠**：同站同油品的在途单据（待发布/已发布）时段不得重叠；
   版本链直接交接的新旧版本在新版本发布时原子替代，不算冲突。
5. **发布冻结与版本**：发布后单据冻结不可改；“调整·另立版本”基于原单生成
   带原因的新版本（站点/油品维度版本号递增），新版本发布时旧版本变为“已被替代”。
6. **撤销恢复**：撤销须填原因，撤销后沿版本链回溯恢复最近有效版本为“已发布”。
7. **价签核验**：含会员优惠的单据发布后须完成价签核验；核验前命中
   `TAG_UNVERIFIED`，会员优惠暂不对会员生效（挂牌价无此约束）。
8. **重载一致性**：从 localStorage 重载后复跑全部规则与版本链完整性校验
   （`BROKEN_LINK`），冲突清单按**站点、油品、时段、命中规则**列出，
   并标注“拦截发布 / 提示·不生效”。

## 目录

- `src/types.ts`：领域模型
- `src/rules.ts`：规则引擎（到手价计算、限价判定、重叠检测、冲突扫描，纯函数）
- `src/seed.ts`：站点、油品、限价与示例单据（含已发布/待复核/待核验各状态）
- `src/store.ts`：Pinia 数据中枢（保存、复核、发布、核验、撤销、版本、持久化、重载）
- `src/demoImport.ts`：含各类违规的外部记录样例，用于演示重载后冲突列出
- `src/components/`：调价单表单、单据卡片（含复核/核验/撤销弹窗）、冲突表
